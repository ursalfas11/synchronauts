# Code of conduct

Synchronauts follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, argue about the code and not about the person, and accept that others see things
differently. Harassment, insults, sexualized language and publishing someone's private information have no place here,
in issues, pull requests, discussions and everywhere else the project is spoken for.

## Reporting

Tell the maintainer in private, through the form at
<https://github.com/ursalfas11/synchronauts/security/advisories/new>. Only the maintainer sees what you write there.
You get an answer within 7 days, and your name is not passed on.

The maintainer may remove comments, commits, issues and other contributions that go against this code, and may block
someone for a time or for good.
